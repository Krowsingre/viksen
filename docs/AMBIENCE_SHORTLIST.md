# Ambience shortlist (for owner approval)

Field recordings to sit under each Dimension as an extra "ambience" layer that rises
and falls with the senses (for example louder when still or at night). Nothing here is
downloaded or used until the owner approves it **and** the licence is confirmed on the
recording's own page. Licence status: **CC0 (seen)** = the licence appeared in search
results; **check** = the page must be opened to confirm.

Preferred licences: CC0 (public domain, no attribution) or a royalty-free licence that
allows commercial use in an app with no attribution.
